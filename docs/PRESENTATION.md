# GraphFlow

## Развитие системы от новостного пайплайна до редактора графов

Проект производственной практики.

Текущий стек: Python, OpenRouter, OrientDB, React 19, React Flow и Three.js.

**Краткий рассказ:** система собирает новости, оценивает их релевантность через LLM, сохраняет результат в графовую базу и предоставляет интерактивный редактор для анализа и развития графа.

- добавлена ортогональная маршрутизация и разнесение параллельных ребер;
- переработано визуальное оформление 2D- и 3D-режимов;

- шаблон можно многократно добавлять в редактируемый граф;
- добавлены проверки циклов, ссылочной целостности и конфликтов ревизий.

**Краткий рассказ:** текущая версия решает задачу управления крупными графами: позволяет скрывать детализацию, повторно использовать типовые фрагменты и сохранять рабочее состояние в OrientDB.

## Текущая архитектура

```text
Google News RSS -> Python -> OpenRouter
                         -> OrientDB -> Graph API -> React Flow / Three.js
                         -> Google Sheets
```

Основные сущности:

- `SearchRun` и `SearchResult` хранят историю поиска и оценки;
- `GraphDocument`, `GraphNode` и `GraphConnection` хранят пользовательские графы;
- `GraphAnnotation` хранит редактируемые поля и координаты;
- `GraphGroup` хранит вложенность и состояние сворачивания;
- `GraphTemplate` хранит повторно используемые структуры.

**Краткий рассказ:** исходные данные, пользовательские правки, группы и шаблоны разделены на самостоятельные сущности и не перезаписывают историю поиска.

## Демонстрация результата

1. Открыть `http://127.0.0.1:5173` и авторизоваться.
2. Показать фильтры, раскладки и переключение `2D/3D`.
3. Выбрать несколько узлов через `Ctrl`, создать и свернуть группу.
4. Обновить страницу и подтвердить сохранение состояния.
5. Сохранить выделенный фрагмент как шаблон.
6. Создать редактируемую копию и добавить шаблон в граф.
7. Показать записи `GraphGroup` и `GraphTemplate` в OrientDB Studio.

Проверки текущей версии: 26 Python-тестов и 10 frontend-тестов проходят, production-сборка выполняется успешно.

**Итог:** создан локально разворачиваемый инструмент поиска, LLM-анализа, хранения и интерактивного редактирования графовых данных.
